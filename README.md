# 浦东铁流 · Pudong Armor

第三人称现代主战坦克对战，战场是压缩成 600 m 见方的上海陆家嘴：世纪大道、明珠环岛、东方明珠、国金中心、金茂大厦、环球金融中心、上海中心。
单个 HTML 文件，无外部素材。

## 运行

```sh
npm install
npm run build        # 生成 dist/index.html（独立页面）和 dist/artifact.html（claude.ai Artifact 用的片段）
python3 -m http.server 8731 -d dist
```

打开 http://localhost:8731 ，点击“开始战斗”后鼠标会被锁定并开始发声。也可以直接双击 `dist/index.html`。

## 技术栈与体积

与参考项目 saltline-fable-5.2 相同的做法：

- three.js r180，用 esbuild 打包、压缩并内联进一个 HTML；字体走 Google Fonts，其余零外部请求。
- 模型、贴图、音效全部在运行时由代码生成：坦克和建筑是程序化几何体，贴图画在 canvas 上，声音用 WebAudio 合成。
- 成品约 0.7 MB（参考项目约 1.4 MB），其中大半是 three.js。

## 玩法

- 可选坦克：ZTZ-99A、T-14“阿玛塔”、T-90M“突破”、M1A2 SEPv3、“豹”2A7V、“挑战者”3、“勒克莱尔”XLR。
- 3v3 / 5v5 / 7v7，对手分新兵、老兵、王牌三档。
- 胜利条件：占满世纪大道与银城中路路口的据点，或击毁全部敌方坦克。8 分钟未分胜负为平局。
- 没有血条。炮弹命中后按入射角计算装甲等效厚度，穿深不够就不穿，角度过大就跳弹；击穿后弹芯与破片在车内飞行，
  逐一杀伤乘员和部件（发动机、传动、油箱、弹药架、炮闩、炮塔驱动、自动装弹机、履带、炮管）。
  弹药架殉爆、只剩一名乘员、起火烧毁都会让车辆出局；带泄压板的尾舱弹药架殉爆不致命。

| 操作 | 按键 |
| --- | --- |
| 行驶 | W A S D，空格制动 |
| 瞄准 / 开火 | 鼠标 / 左键 |
| 自由观察 | 按住右键 |
| 瞄准镜、倍率、镜头距离 | Shift、滚轮 |
| 换弹 | 1 穿甲弹 · 2 破甲弹 · 3 高爆弹 |
| 战地维修 | 停车后按 F |
| 暂停 | Esc |

触屏：左侧摇杆行驶，右侧滑动瞄准，按钮开火、瞄准镜、换弹、维修。
