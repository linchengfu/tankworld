# 浦东铁流 · Pudong Armor

第三人称现代主战坦克对战，战场是压缩成 600 m 见方的上海陆家嘴：世纪大道、明珠环岛、东方明珠、国金中心、金茂大厦、环球金融中心、上海中心。
单个 HTML 文件；天空和地面用了内联的 CC0 实拍素材，其余由代码生成。

## 运行

```sh
npm install
npm run bake         # 改过坦克几何后重新烘焙环境光遮蔽（写入 src/tank/ao.gen.js，约 20 秒）
npm run build        # 生成 dist/index.html（独立页面）和 dist/artifact.html（claude.ai Artifact 用的片段）
python3 -m http.server 8731 -d dist
```

打开 http://localhost:8731 ，点击“开始战斗”后鼠标会被锁定并开始发声。也可以直接双击 `dist/index.html`。

## 技术栈与体积

与参考项目 saltline-fable-5.2 相同的做法：

- three.js r180，用 esbuild 打包、压缩并内联进一个 HTML；字体走 Google Fonts，其余零外部请求。
- 坦克和建筑是程序化几何体，涂装和立面贴图画在 canvas 上，声音用 WebAudio 合成（发动机点火脉冲、逐节履带声、炮声回波、装填全过程），没有采样任何游戏的音频。
- 实拍素材来自 Poly Haven（CC0，见 `assets/CREDITS.md`）：一张带云的天空全景（4K JPG 做背景、1K HDR 提供光照和反射）和三套地面材质（沥青、人行道砖、广场砖）。它们以 data URL 内联进 HTML，解码失败时自动退回程序化贴图。
- 每辆坦克的环境光遮蔽在构建前离线烘焙：`tools/bakeao.mjs` 让每个顶点向整车投射一束短射线，结果按顶点存进 `src/tank/ao.gen.js`。
- 成品约 6 MB：素材约 4 MB，烘焙数据约 1 MB，其余是 three.js 和游戏代码。

## 玩法

- 可选坦克：ZTZ-99A、T-14“阿玛塔”、T-90M“突破”、M1A2 SEPv3、“豹”2A7V、“挑战者”3、“勒克莱尔”XLR。
- 3v3 / 5v5 / 7v7，对手分新兵、老兵、王牌三档。
- 胜利条件：占满世纪大道与银城中路路口的据点，或击毁全部敌方坦克。8 分钟未分胜负为平局。
- 没有血条。炮弹命中后按入射角计算装甲等效厚度，穿深不够就不穿，角度过大就跳弹；击穿后弹芯与破片在车内飞行，
  逐一杀伤乘员和部件（发动机、传动、油箱、弹药架、炮闩、炮塔驱动、自动装弹机、履带、炮管）。
  弹药架殉爆、只剩一名乘员、起火烧毁都会让车辆出局；带泄压板的尾舱弹药架殉爆不致命。

| 操作 | 按键 |
| --- | --- |
| 行驶 | W A S D，空格制动 |
| 瞄准 / 开火 | 鼠标 / 左键 |
| 自由观察 | 按住右键 |
| 瞄准镜、倍率、镜头距离 | Shift、滚轮 |
| 换弹 | 1 穿甲弹 · 2 破甲弹 · 3 高爆弹 |
| 战地维修 | 停车后按 F |
| 暂停 | Esc |

触屏：左侧摇杆行驶，右侧滑动瞄准，按钮开火、瞄准镜、换弹、维修。

## 画面与车辆数据

**车辆建模流程**：先找公开的三视图，在图上叠加米制网格，量出车体侧面轮廓、负重轮/主动轮/诱导轮位置、炮塔俯视轮廓、
各部件位置，再把这些数值写进 `src/tank/vehicles.js`。`tools/modelshot.cjs` 能把模型渲染成正交侧视/俯视/正视图，用来和图纸逐项对照。

| 车型 | 所用图纸（the-blueprints.com / drawingdatabase.com） | 说明 |
| --- | --- | --- |
| ZTZ-99A | PLA ZTZ-99A2 彩色四视图 | 以车宽 3.7 m 定比例，全长 11.0 m 与公开数据吻合 |
| T-14 | T-14 Armata 侧视线图；带尺寸标注的三视图 | 全长 10.889 m、负重轮 Ø700 mm 取自图上标注 |
| T-90M | T-90 四视线图（“突破”构型） | 以全长 9.53 m 定比例，车宽 3.78 m 吻合 |
| M1A2 | M1A2 TUSK 五视线图 | 车体与炮塔按图；SEPv3 的 CROWS 武器站等按公开照片 |
| “豹”2A7V | Leopard 2A5 四视线图 | 车体、炮塔轮廓与 2A5 相同；L55 身管、车首附加装甲按公开照片 |
| “挑战者”3 | Challenger 2 彩色五视图 | 车体按图；新炮塔没有找到图纸，按公开照片估计 |
| “勒克莱尔”XLR | Leclerc AMX-56 四视线图 | 俯视图比例偏小 7%，已换算；XLR 的格栅装甲、武器站按公开照片 |

- 车体和炮塔按截面蒙皮成平直的焊接装甲板；负重轮、主动轮齿圈、诱导轮各自成形，履带沿真实的轮系路径绕行。
- 履带是沿轮系路径排布的一节节履带板（实例化网格，带导向齿、端联器和橡胶垫/钢齿），随行驶沿路径滚动。
- 表面对照实车照片校对：99A 的数码迷彩按 6 cm 网格的矩形色块和实车配色生成，带八一军徽；T-90M 为灰绿哑光漆和阅兵涂装的
  圣乔治丝带标识；两车的圆弧前挡泥板、裙板下缘缺口、炮塔下的防破甲网按照片补上。漆面保持干净锐利，泥尘只在着色器里加在车体下部。
- 同一个网格里用逐顶点的“表面类别”区分涂装、橡胶、裸钢、玻璃，着色器据此给出不同的粗糙度和金属度。
- 画面是雨后放晴的白天：实拍天空提供光照，路面仍是湿的。湿路面沿用 [Saltline](https://github.com/realcodebear/saltline-fable-5.2) 的做法
  （干 → 潮 → 积水的连续过渡，积水用平面反射成镜，潮湿沥青读取反射图的模糊层级并朝视线方向拉长，带雨圈）。
- 东方明珠、上海中心、环球金融中心、金茂大厦、国金中心、陆家嘴环岛天桥等地标保留。
- 机动与火力数据取自公开资料并标注了口径不一之处：T-90M 倒车约 5 km/h、“豹”2A7V 极速约 63 km/h、“挑战者”3 为 1200 马力、
  各车备弹按公开总数分配（99A 42、T-14 45、T-90M 43、M1A2 42、“豹”2A7V 42、“挑战者”3 31、“勒克莱尔”40）。
- 装甲等效厚度和穿深没有权威公开数据，仍是为可玩性设定的估值。图纸只用于量取尺寸，游戏里不包含任何图纸或照片。
